# Poultry Farm Management App

Owner and farmer portal for daily poultry reports (deaths, feed bags, average weight).
Installable on phones as an app. Data is stored in each browser (localStorage).

## Publish on GitHub Pages
1. Create a new repository on GitHub (public).
2. Upload ALL files from this folder (index.html, manifest.webmanifest, sw.js, icons) to the repository root.
3. Go to Settings > Pages > Source: "Deploy from a branch", Branch: main, folder: / (root). Save.
4. After a minute your app is live at https://YOUR-USERNAME.github.io/REPOSITORY-NAME/
5. On the phone open that link, then Install app (Android) or Share > Add to Home Screen (iPhone).
